# Arrow Out

복잡하게 꺾인 화살표의 이동 경로를 풀어 중앙의 분홍 화살표를 탈출시키는 모바일 웹 퍼즐입니다.

## 게임 규칙

- 각 화살표는 여러 칸을 차지하는 하나의 직교 폴리라인입니다.
- 화살표를 누르면 화살촉이 먼저 전진하고 뒤쪽 몸통은 이미 그려진 경로를 그대로 따라갑니다.
- 선은 모양을 유지한 채 평행 이동하지 않고, 줄이나 뱀이 풀리듯 굴절점을 순서대로 통과합니다.
- 화살촉부터 보드 가장자리까지 새로 지나갈 출구 경로에 다른 화살표가 없어야 제거됩니다.
- 화살촉의 출구가 자신의 꼬리나 몸통을 다시 가로지르는 화살표는 생성하지 않습니다.
- 다른 화살표를 순서대로 제거해 분홍 화살표의 이동 통로를 만드세요.

## 퍼즐 품질 보장

레벨은 정답의 마지막 수부터 역순으로 배치합니다. 각 화살표를 추가할 때 나중에 남아 있을 화살표들을 피해 탈출 가능한지 검사하며, 완성 후에는 인증된 제거 순서와 독립 DFS 솔버로 다시 검증합니다. 검증을 통과하지 못한 보드는 플레이에 사용하지 않습니다.

## 100레벨 캠페인

- 1~100레벨 동안 보드가 11×11에서 최대 20×20로 커집니다.
- 화살표 수, 평균 길이, 굴절 횟수와 점유 밀도가 단계적으로 증가합니다.
- 하트, 다이아몬드, 나선, 번개, 왕관형 화살표가 고레벨로 갈수록 자주 등장합니다.
- 일반 60개, 횟수 제한 20개, 타임어택 20개 스테이지로 구성됩니다.
- 횟수와 시간 제한은 각 퍼즐의 실제 목표 의존 화살표 수를 기준으로 계산됩니다.
- 최고 해금 레벨과 레벨별 최고 기록은 브라우저에 저장됩니다.
